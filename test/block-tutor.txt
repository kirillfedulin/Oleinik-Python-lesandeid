Конечно 🙂 Вот **шпора по диаграммам (блок-схемам) для программистов** — кратко и по делу.

---

## 📊 Основные элементы блок-схем

### 🔵 Овал — **Начало / Конец**

**Когда использовать:**

* Старт алгоритма
* Завершение алгоритма

**Подпись:**
`Start`, `Начало`, `End`, `Конец`

---

### 🟦 Прямоугольник — **Процесс / Действие**

**Когда использовать:**

* Любая операция
* Присваивание
* Вычисления
* Вызов функции

**Примеры:**

* `i = i + 1`
* `sum = a + b`
* `print(x)`

---

### 🔶 Ромб — **Условие / Ветвление**

**Когда использовать:**

* `if / else`
* `while`
* `for` (проверка условия)
* `switch` (иногда)

**Особенности:**

* **2 выхода** (Да / Нет, True / False)

**Примеры:**

* `x > 0?`
* `i < n?`

---

### 🟪 Параллелограмм — **Ввод / Вывод**

**Когда использовать:**

* Ввод данных
* Вывод на экран
* Чтение/запись

**Примеры:**

* `Ввести n`
* `Вывести результат`
* `read(x)`

---

### ➡ Стрелка — **Поток управления**

**Когда использовать:**

* Переход между блоками
* Показывает порядок выполнения

---

### ⭕ Малый круг — **Соединитель**

**Когда использовать:**

* Если схема большая
* Для перехода между частями схемы
* Чтобы не тянуть длинные стрелки

---

### 🟫 Прямоугольник с двойной линией — **Подпрограмма**

**Когда использовать:**

* Вызов функции
* Процедуры
* Метода

**Пример:**

* `sort(array)`
* `calculateSum()`

---

## 🧠 Быстрые правила (чтобы не путаться)

| Если ты…                    | Используй             |
| --------------------------- | --------------------- |
| Начинаешь или заканчиваешь  | Овал                  |
| Что-то считаешь или меняешь | Прямоугольник         |
| Проверяешь условие          | Ромб                  |
| Читаешь или выводишь        | Параллелограмм        |
| Вызываешь функцию           | Двойной прямоугольник |

---

## 🔁 Пример: `if`

```
   ◯ Start
      ↓
  🔶 x > 0?
   ↓Да     ↓Нет
🟦 y=1   🟦 y=-1
      ↓
   ◯ End
```

---

## 🔁 Пример: `while`

```
   ◯ Start
      ↓
  🔶 i < 10?
   ↓Да
🟦 i = i + 1
      ↑
      └─────
   ↓Нет
   ◯ End
```
